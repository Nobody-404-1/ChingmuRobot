Abstract

About the Dataset

ChingMu 1000-Hour Embodied Motion Dataset 是一个面向人形机器人、灵巧手、具身 AI 和虚拟制作构建的 高精度、多模态、可复现动作数据基础设施。

数据通过光学动作捕捉系统采集，覆盖人体全身运动、手指精细动作、物体 6D 位姿、多视角视频、任务标签和质量检测报告； 场景覆盖工业制造、家庭服务、商超零售、医疗康养、物流仓储、农业食品与文娱表演等典型应用。

通过标准化采集、自动化清洗标注、机器人重定向和质量评估流程，为 模仿学习、动作生成、仿真训练与真实机器人部署提供高质量数据底座。

Data Modalities

What's Inside the Dataset

Finger Motion

手指精细动作

捏、抓、拧、插拔、按键、镊子/螺丝刀/剪刀工具使用，适配灵巧手训练数据格式。

Object 6D Pose

物体位姿与刚体追踪

人手、道具、商品在同一坐标系同步采集，输出每帧 6DoF pose + bounding info。

Robot Retargeting

面向机器人的重定向数据

Human→Robot skeleton retargeting + MuJoCo/Isaac 仿真校验 + 滑步/穿模/抖动质量报告。

Multi-view Video

多视角同步视频

与 mocap 帧时钟对齐的多机位影像，可作为视觉模型输入 / 虚实对照 / 质量校验。
